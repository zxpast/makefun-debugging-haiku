One haiku about debugging, in the 5-7-5 shape:

> Black screen, one red wound.
> The error names a ghost file.
> I killed it last week.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes the haiku to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Node 22 standard library only, fully deterministic: same bytes on every run, no network.
